# 2D DRIVER
Playable HTML/CSS/JavaScript 2D endless hill-climb prototype using generated art assets.

## Run
- Desktop: `python server.py` then open `http://127.0.0.1:8000`
- Mobile/cloud IDE: upload this folder and run the Python server, or serve the folder with any static web server.

## Controls
- Right / D: gas
- Left / A: reverse / balance
- Space: brake
- Mobile: GAS and BRAKE buttons

## Included
Main menu, vehicle garage, map selection, endless procedural terrain, vehicle motion, suspension-style chassis correction, fuel, coins, distance, pause/restart, 16 vehicles, 12 maps.
